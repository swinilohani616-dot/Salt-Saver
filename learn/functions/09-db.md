### `computeDiff(current, records, snapshot)`
- **What:** new, changed, removed, unchanged. Inside, `count` counts one kind.
- **Why:** you approve *changes*, not a whole file.

### `stageImport(db, adapter, file)`
- **What:** file → rows → differences → report. `cellOf` reads a cell by field name. **The catalogue does not change.**
- **Guards:** same file, another review waiting, no readable row, an older file read again.

### `approveImport(db, adapters, diffId, review)`
- **What:** saves everything in one transaction.
- **Guards:** your name is required; the review must still be up to date; too many removals are refused (more than 20% **and** more than 20).

| Function | What | Why |
|---|---|---|
| `rejectImport(db, id, { ... })` | Throws it away | Nothing changes |
| `listImports(db)` | List | |
| `getImport(db, id)` | One | |
