# 11. Glossary

## Medicine words

| Word | Meaning |
|---|---|
| Salt / active ingredient | The part that treats you, like paracetamol |
| Brand | The company's name, like Crocin |
| Generic | Sold under the salt name |
| Jan Aushadhi | Government programme for lower-priced generics |
| PMBI | The bureau that runs Jan Aushadhi and publishes its price list |
| NPPA | The authority that controls medicine prices |
| Pharma Sahi Daam | NPPA's public page for medicine prices |
| MRP | Maximum Retail Price, taxes included |
| Ceiling price | Legal maximum set by NPPA, taxes **not** included |
| GST | Tax. 5% is used in the ceiling check |
| Scheduled medicine | One that has a ceiling price |
| Composition | Salts with their strengths |
| Strength | How much: 500 mg, 250 mg/5 ml |
| Dosage form | Tablet, capsule, syrup, injection… |
| Route | How it is taken: mouth, eye, skin, injection |
| Release type | How fast it is released. IR = ordinary. SR, ER, XR, XL, MR, CR, PR = slow. DR = delayed (enteric coated) |
| Salt form | The exact chemical version, like *hydrochloride* |
| IP, BP, USP | Quality standards (Indian, British, American) |
| "eq. to" | "equivalent to": 1250 mg calcium carbonate eq. to 500 mg calcium |
| Formulation | Salts + strengths + form + route + release type |
| Combination | More than one salt in one medicine |

## Project words

| Word | Meaning |
|---|---|
| Reference price | The price you compare with: the brand's, or yours |
| Verified price | From an official list, or checked from a pack by a named person |
| Entered by you | Typed from your pack |
| Demo data | The first 28 made-up records |
| Illustrative | Price type of demo data. Never shown |
| Formulation key | One text that identifies a formulation |
| Composition key | Salts and strengths only |
| Verified match | Everything matches |
| Strip check | Asking what your strip says about SR, ER… |
| Stage | Prepare an import without saving it |
| Diff | The list of differences |
| Stale | Too old |
| Seed | First data put in an empty database |
| PRD | Product Requirements Document |

## Programming words

| Word | Meaning |
|---|---|
| Function | A named piece of code that does one job |
| Parameter | What you give a function |
| Return | What a function gives back |
| Module | A file that shares functions with `export` / `import` |
| Pure function | Same input, same output, touches nothing else |
| Async / await | Waiting for something slow without freezing |
| Promise | "I will give you the answer later" |
| Map, Set | A list of pairs; a list without doubles |
| Regex | A pattern for finding text |
| JSON | A text format for data |
| DOM | The page as objects JavaScript can change |
| Event | Something that happened (click, typing) |
| Debounce | Wait until typing stops |
| State | What is true right now |
| Render | Draw on the screen |
| Front end / back end | What runs in the browser / on the server |
| Endpoint | One address of an API |
| HTTP status | 200 fine, 400 your mistake, 404 not found, 429 too many, 503 not available |
| Middleware | Code that runs before the main answer |
| Rate limit | Not more than N requests |
| SQL | Language for databases |
| Query | A question to the database |
| Transaction | All or nothing |
| Migration | A numbered change to the tables |
| Upsert | Insert, or update if it exists |
| Pool | A few database connections, shared |
| RLS | Row Level Security: who may read which rows |
| Checksum (SHA-256) | A fingerprint of a file |
| Environment variable | A setting outside the code |
| CSP | Content Security Policy: what a page may load |
| XSS | An attack with harmful text in a page |
| CDN | Servers that deliver common files |
| WCAG | Rules for accessible pages |
| ARIA | Extra information for screen readers |
| CI | Automatic tests on every push |
| Cron | A timetable for jobs |
| Serverless | A function that runs only when asked |
