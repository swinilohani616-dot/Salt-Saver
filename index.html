Savings calculator

How it works

1. Search

Type a brand name or an active ingredient. Matching ignores upper and lower case.

2. Match the composition

Records are grouped only when they list the same ingredients, same strengths and same dosage form in the sample data. A 500 mg tablet is never compared with a 650 mg one.

3. Compare unit prices

Prices are compared per tablet, capsule or ml, so packs of different sizes are compared fairly.

About this project

SaltSaver (project PST_PD_096) is a college on-the-job-training web development project. It explores how a simple website could help people understand that medicines with the same active ingredient can be sold at very different prices.

This is Phase 1: search, comparison cards and a savings calculator, built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript using a small fictional JSON dataset.

Important: Two products having the same listed ingredients does not prove they are interchangeable for any particular person. Decisions about medicines should be made with a qualified doctor or pharmacist.
